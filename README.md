# NutriSelf EC

Plataforma digital de nutrición clínica desarrollada con Laravel.

## Stack Tecnológico

- Laravel 12
- FilamentPHP
- TailwindCSS
- MySQL
- Hostinger
- OpenAI API
- WhatsApp Integration

## Objetivo

Construir un ecosistema digital para:
- captación de pacientes,
- reservas,
- automatización,
- marketing,
- atención inicial con IA.
